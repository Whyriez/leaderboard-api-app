Leaderboard API
Self-Host

Server leaderboard untuk banyak game sekaligus. Admin membuat apiKey dan secretKey lewat endpoint protected, lalu client game memakai x-game-key untuk baca data dan x-signature untuk submit skor secara aman.

Endpoint Utama

POST/admin/games POST/admin/boards POST/v1/submit GET/v1/boards/:slug

Credentials

  • apiKey adalah key publik game dan dipakai sebagai x-game-key.
  • secretKey adalah secret privat untuk HMAC signing.
  • ADMIN_SECRET hanya untuk admin endpoint di worker.

Local Dev

Isi .dev.vars untuk wrangler dev, lalu jalankan server local dengan npm run dev.

Security Note

Jangan simpan secretKey di client publik jika bisa dihindari. Idealnya signing dilakukan di backend game sendiri.
